# Batched PSBD sweep jobs

Generated by `pbs/generate_batched_jobs.py`. Roughly 7 checkpoints x 3 placements per
job, sized to about 4 hours of work under a 6 hour walltime, which is the granularity
the cluster asked for after the earlier one-checkpoint-per-job layout.

## Two naming generations, and the false alarm they cause

The generator originally numbered every job `batch_{index:03d}` regardless of
architecture, so a Swin run overwrote the ViT files of the same index. It now emits
`{architecture}_{index:03d}`.

The consequence is that **`vit_001.pbs` through `vit_030.pbs` are a renamed
regeneration of work that already ran as `batch_001.log` through `batch_030.log`**.
Their logs are under the old name, so any check that pairs `<file>.pbs` with
`<file>.log` reports all 30 as never submitted. They are not. Verified 2026-08-14:
**199 of 199 checkpoint slots across those files already have `results/*/psbd/`
output.**

The general lesson, which cost a false alarm about 330 pending jobs: **check against
results, not against filenames.** File naming is a convention that changes; the
presence of a config directory is the fact.

## Re-running is safe

Every job passes `--skip-existing`, which resolves through
`psbd_dropout_sweep.cache_config_name` and skips any (placement, rate, split) already
cached. Resubmitting a completed job is a no-op that costs 1 job slot, so when in
doubt, resubmit rather than reason about it.

The 1 exception is a job that overrides `--forward-passes`. Caches at k != 3 carry a
`_k{n}` suffix precisely so they cannot collide with, or be skipped because of, the
k = 3 caches.

## What actually was stalled

`swin_005.pbs` through `swin_032.pbs`, 28 jobs, generated but never submitted. The
sweep monitor showed `swin_checkpoints` flat at 11 for an entire session while the ViT
config count more than doubled, and a stalled arm looks exactly like a slow one in
that counter. Submitted 2026-08-14, see
[docs/runs/2026-08-14-swin-batch-completion.md](../../docs/runs/2026-08-14-swin-batch-completion.md).
