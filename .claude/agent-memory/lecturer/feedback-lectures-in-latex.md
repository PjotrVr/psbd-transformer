Every lecture is a LaTeX document compiled to PDF, never a markdown file (user, 2026-09-17,
after a first draft landed as markdown).

**Why:** the user's lecture-notes format ("skripta") is LaTeX with figures produced from verified
numbers, and they read and teach from the PDF.

**How to apply:**
- One document per course: `lectures/<version>/main.tex` compiled to `main.pdf`, chapters in
  `chapters/NN-name.tex`, one abstract, one table of contents, one bibliography, one appendix of
  what was verified, a ranked "future lectures" section and a course synthesis chapter. `verify/NN-name.py`
  and `figures/NN-name/` per chapter. No per-lecture PDFs. A markdown `README.md`
  is the table of contents only.
- Compile with `~/.local/bin/tectonic main.tex` (no pdflatex on the cluster). Fix every error;
  check the log for overfull boxes and undefined references before delivering.
- Each lecture: abstract (what is covered, what the reader can do at the end, assumed background);
  the concrete problem before the object it forces; the engineering as it exists in the repository
  with measured numbers cited to `results/` paths; the mathematics with every symbol defined where
  introduced and a symbol table beside every formula; a synthesis (relationship or master reference
  table, a short "what to actually remember" list); an appendix listing what was verified
  numerically versus asserted. For this course each lecture also ends with "What v2 changes".
- No exercises, no Anki cards, no cheat sheet for the course lectures.
- one `verify` script per chapter with `--fast` and `--slow`; numeric figures are generated by it into
  `figures/` from the result files, so plotted numbers are verified numbers. High contrast, series
  told apart by line style and marker. Conceptual diagrams are inline TikZ. Nothing over a minute,
  nothing on the GPU, matplotlib in a separate `lectures/<version>/.venv`, never the project venv.
- Honesty over polish: a measured result with an interval, a single-seed number and an unrun design
  read differently; an unsourced number is stated as absent, never invented.
- Citations: one author named; more than one is first author plus "et al." Our own results cited
  by file path.
- Colours: blue accent, green for positive results, red for negative results. Packages: amsmath,
  amsthm, booktabs, tikz, hyperref. Clean, direct, real university lecture notes.
- Prose follows `.claude/styles/math-style.md` and `writing-style.md`; results before derivations.
