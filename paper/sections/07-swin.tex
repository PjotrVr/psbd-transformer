\section{Transfer to Swin-S}
\label{sec:swin}

Swin-S restricts attention to shifted windows and merges patches between stages, so tokens mix locally within a stage and only reach every other token through merging. If the account of \cref{sec:mechanism} is right, a token mask before the attention LayerNorm should still remove routed evidence, since every route still passes through windowed attention, and the site should still beat post-residual dropout. \Cref{tab:swin} reads the same placements on 53 to 60 backdoored Swin-S models over CIFAR-10, CIFAR-100 and GTSRB. No attack implants on Tiny ImageNet on Swin at any rate we tried.

The ranking transfers. Attention-input token masking reaches 0.968 with 1 model below chance, against 0.871 and 5 for post-residual dropout, a paired gain of +0.091 close to the ViT gain of +0.103.

The last block of the table is the control that separates site from perturbation on Swin as \cref{tab:operators} did on ViT. Moving dropout, the paper's perturbation, from the residual stream to the attention input gains nothing, with $-$0.022 and an interval containing 0. Moving to token masking at that same input gains +0.091. On Swin as on ViT, the perturbation that removes whole tokens is what the attention input rewards, and windowing does not change that.

2 differences remain. WaNet is detected worse on Swin than on ViT, at 0.26 to 0.29 against 0.51 to 0.55 with dropout at the matched rate on CIFAR-100. This is consistent with a warping trigger that windowed attention spreads across windows before any single window can be masked away. And the Swin models have not been swept over the full 18-placement basis, so the Swin ranking rests on 5 placements rather than 18. That sweep is in progress.
