\section{Introduction}
\label{sec:intro}

A backdoored classifier behaves normally on clean inputs and predicts an
attacker's class whenever a trigger appears in the input
\cite{li2022backdoorsurvey}. The attacker plants the behavior by poisoning a
small share of the training data, often 1\% or less. The defender receives the
trained model without ever seeing that data. Input-level detection asks the
most practical question in this setting. Given the deployed model and 1 incoming
input, is that input carrying a trigger? A detector that answers well runs in
front of the model in production, needs no retraining and can be paired with a
removal defense later.

Prediction Shift Backdoor Detection (PSBD) \cite{li2025psbd} is such a detector.
Its observation is that a backdoored input is decided by a shortcut the model
learned quickly and firmly, while a clean input is decided by a broad set of
features. When the network is perturbed at inference the broad decision wobbles
and the shortcut holds. PSBD therefore runs the model a few times with dropout
active, measures how much the probability of the predicted class falls and flags
the inputs whose prediction barely moves. It needs only a small clean validation
set to set its threshold, and on ResNet-18 and VGG-16 it reports strong results
across 7 attacks.

Nothing in that argument depends on convolutions, yet the perturbation does not
carry over unchanged. A ResNet basic block has 1 natural place for dropout, the
residual stream after the add, and the original work put it there. A transformer
block has no such default. The input to attention, the input to the MLP, each
branch output before its residual add, the stream after each add, the attention
heads and the MLP hidden units are all different tensors with different roles.
Dropout is also not the only thing that can be injected. Whole tokens can be
masked, channels can be masked, noise can be added before a LayerNorm or its
gain can be scaled, and each interacts differently with the attention and the
normalization that follow.

\paragraph{Research questions.} Adapting PSBD to a Vision Transformer (ViT)
\cite{dosovitskiy2021an} is therefore a design problem on 2 axes, where to
perturb and what to inject, and we ask 3 questions about it.

\begin{enumerate}
  \item \textbf{Does the choice matter?} If every site and operator scored alike,
    the original placement would transfer and there would be nothing to study. We
    measure the whole design space on 1 fixed set of backdoored models under 1
    decision rule.
  \item \textbf{Do the 2 axes separate?} A ranking of placements is only a search
    result. It becomes a finding when the site and the operator can be shown to
    act independently, so that neither collapses into the other.
  \item \textbf{Why does the winner win?} A ranking that no mechanism explains
    predicts nothing about the next architecture or the next attack. We ask what
    a ViT backdoor is, and whether knowing that predicts the ranking we measured.
\end{enumerate}

The answers are that the choice decides the outcome, that the axes separate, and
that 1 mechanism predicts both. Masking whole tokens at the input of every
attention block, which we call PSBD-TM, reaches a mean AUROC of
\HeadlineAurocAdaptive against \PublishedAurocAdaptive for our reading of the
original placement, which we call PSBD-RD. The 2 axes separate because the same
operator moves by \AttentionInputMinusMlpInputTokenMask between the attention
input and the MLP input, while at the attention input alone the operator moves the
score by \GaussianMinusTokenMaskAttentionNorm, and what decides the operator is not the
site but the side of the LayerNorm the perturbation lands on. Holding that side
fixed leaves no interaction between the 2 axes that we can separate from 0. The mechanism is that a backdoor in a ViT is 1 direction in
the residual stream, written in the last third of the network and routed through
attention from the trigger's patch tokens to the class token.

  \item A refutation. The claim that dropout before the residual add beats

    tokens over coordinates and the reversal through LayerNorm absorption, and it
    predicts which attacks show the shift toward the target class that the
    original work describes (\cref{sec:mechanism}).
\end{enumerate}
