\section{Transfer to Swin-S}
\label{sec:swin}

Swin-S restricts attention to shifted windows and merges patches between stages, so tokens mix locally within a stage and only reach every other token through merging. If the account of \cref{sec:mechanism} is right, a token mask before the attention LayerNorm should still remove routed evidence, since every route still passes through windowed attention, and the site should still beat the residual stream. \Cref{tab:swin} reads the same placements on 53 to 60 backdoored Swin-S models over CIFAR-10, CIFAR-100 and GTSRB. No attack implants on Tiny ImageNet on Swin at any rate we tried.

The ranking transfers. PSBD-TM reaches 0.968 against 0.871 for PSBD-RD, a paired gain of +0.091 close to the ViT gain of +0.103. The last block of the table is the control that separates the site from the perturbation on Swin as \cref{tab:staircase-operators} did on ViT. Moving dropout from the residual stream to the attention input gains nothing on Swin, with $-$0.022 and an interval containing 0, while moving to token masking at that same input gains +0.091. On Swin the perturbation that removes whole tokens is what the attention input rewards, and windowing does not change that.

2 differences remain. PSBD-TM detects WaNet worse on Swin than on ViT, at 0.26 to 0.29 against 0.51 to 0.55 on CIFAR-100, which is consistent with a warping trigger that windowed attention spreads across windows before any single window can be masked away. And the Swin models have not been swept over the full basis, so the Swin ranking rests on 5 placements rather than 18. That sweep is in progress.
