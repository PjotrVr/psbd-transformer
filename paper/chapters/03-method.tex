\section{Method}

\subsection{Scores}

We keep PSBD's quantities in the paper's own notation. With $\mathcal{Y}(\mathbf{x};\boldsymbol\theta)$ the class the model $\boldsymbol\theta$ predicts without dropout, $\mathcal{Y}(\mathbf{x};\boldsymbol\theta')$ the class predicted with dropout active in the forward pass, $k$ the number of dropout passes and $\mathcal{D}$ any dataset,
\begin{equation}
\ps(\mathbf{x}) = \mathbb{I}\big(\mathcal{Y}(\mathbf{x};\boldsymbol\theta) \neq \mathcal{Y}(\mathbf{x};\boldsymbol\theta')\big),
\qquad
\sigma(\mathcal{D}) = \frac{1}{k\,|\mathcal{D}|} \sum_{\mathbf{x}\in\mathcal{D}} \ps(\mathbf{x}),
\end{equation}
and with $c$ the no-dropout prediction, $P_c(\mathbf{x};\boldsymbol\theta)$ its confidence and $P_c(\mathbf{x};p,\boldsymbol\theta_i')$ the confidence of that same class on the $i$th pass at dropout rate $p$,
\begin{equation}
\psu(\mathbf{x}) = P_c(\mathbf{x};\boldsymbol\theta) - \frac{1}{k}\sum_{i=1}^{k} P_c(\mathbf{x};p,\boldsymbol\theta_i'),
\qquad
c = \arg\max_{c\in\mathcal{C}} P(\mathbf{x};\boldsymbol\theta).
\end{equation}
The headline statistic of this paper is the fractional form, which divides the drop by the starting confidence,
\begin{equation}
\psu^{\mathrm{ratio}}(\mathbf{x}) = 1 - \frac{\frac{1}{k}\sum_{i=1}^{k} P_c(\mathbf{x};p,\boldsymbol\theta_i')}{P_c(\mathbf{x};\boldsymbol\theta)},
\end{equation}
so that a sample starting near full confidence has no more room to fall than a sample starting lower. The absolute form is computed beside it on every cell, and the fractional form separates better across the whole grid, which answers the objection that PSU is a proxy for baseline confidence. Low score means poisoned, the rule is one-sided, and no number in this paper reads the larger of an AUROC and its complement.

\subsection{Positions and operators}

A placement is a position and an operator. The position is a named boundary inside every block, \PositionCount{} of them on ViT, of which \SinglePositionCount{} are swept in isolation: the patch embedding, the input of the attention LayerNorm, the normalised attention input, the attention branch's output, the stream after the attention add, the input of the MLP LayerNorm, the normalised MLP input, the MLP branch's output and the stream after the MLP add. \StructuredPositionCount{} more expose a transformer unit, the per-head outputs and the MLP hidden neurons, and \PortedPositionCount{} host ported detectors, the outputs of the LayerNorms and the input pixels. The published ConvNet placement, dropout after every residual add, is the pair of stream positions, and the founding pre-residual placement is the pair of branch outputs. A position attaches a fresh perturbation module through a forward hook on that boundary, never by switching on a dropout the model already contains, because a trained dropout's inverted scaling was calibrated against the next layer's weights and switching it back on at inference would conflate the model's own regularisation with the probe. The pair of positions that perturb a tensor which never crosses a module boundary use a removable forward wrapper instead.

The operator is what the module does, \OperatorCount{} kinds in the registry. Dropout draws an independent mask per token and channel. A token mask zeroes whole tokens, never the class token, and a channel mask zeroes whole channels shared across a sample's tokens. DropPath zeroes a whole branch output. Gaussian and Rademacher noise add zero-mean noise at the activation's own per-sample scale and remove nothing. A head mask zeroes whole attention heads. The ported operators amplify rather than remove, a LayerNorm output for IBD-PSC \citep{hou2024ibdpsc} and the input pixels for SCALE-UP \citep{guo2023scale}, and both are deterministic so a single pass is exact. Every masking operator keeps dropout's inverted scaling so the expected activation is unchanged, and no operator uses an absolute noise scale, which is what makes a comparison across positions of different activation energy well posed.

\subsection{Rate rules}

The paper's adaptive rule is the smallest rate whose clean validation shift ratio reaches \AdaptiveShiftTarget{}. Only that half of the paper's rule transfers, since the other half maximises the gap between the training pool's shift ratio and the validation's, and our scored pool is clean by construction. It reads clean data only and is the deployable rule every headline number uses. A second rule exists for comparing placements. The same nominal rate is a different intervention at every position, a branch output perturbed once against a stream masked once per block so that only $(1-p)^{\VitBlocks}$ of coordinates survive the stack, and a comparison at a shared rate is decided by whichever arm perturbs harder. The matched rule instead picks, for each placement, the rate whose clean validation shift ratio sits nearest \PlacementMatchTarget{}, on a ladder of \ShiftMatchTargets{}, and it is deliberately below the adaptive target because the destructive placements have already saturated at \AdaptiveShiftTarget{} and the ranking compresses there. A placement whose ladder never reaches a target has no value at that rule, and the table says so rather than substituting the nearest rate.

\subsection{Threshold and metrics}

The threshold is the \HeadlineQuantile{} quantile of the fractional PSU of the \HeldoutSize{} held-out clean images, PSBD's own choice, with \PsbdQuantiles{} swept beside it since the quantile is the false-positive budget and \HeadlineQuantilePercent{} is a quarter of clean data discarded. The clean and triggered test pools are paired image for image, restricted to the images eligible for the attack, so AUROC never measures which classes were dropped. AUROC at the headline quantile's rate is the number every comparison reads, TPR at each budget is reported beside it, and FPR is uninformative by construction since the threshold is a quantile of the same clean distribution. Each run uses $k = \ForwardPasses$ passes with mask seed \MaskSeed{}, and every interval in this paper is a \BootstrapResamples{}-resample bootstrap over cells at seed \BootstrapSeed{}, paired within cell.
