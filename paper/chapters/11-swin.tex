\section{Swin-S}
\label{sec:swin}

\begin{claim}{SUPPORTING}{F19}
A placement result on a single architecture could be a property of that architecture's block. Swin-S has \SwinBlocks{} blocks, windowed attention, no class token and a token-mean readout, and shares every position name with ViT through the registry, so the same placement runs unchanged. If the recommended placement's gain over the published one held there, it would be evidence that the placement is about the transformer block and not about ViT-B/16.
\end{claim}

Swin has no coverage ledger and no basis sweep, so \cref{tab:swin-placements} reads every cached placement on the \SwinCells{} Swin folders whose sidecar attack success clears the bar, over \SwinDatasets{} datasets with no Tiny cell, and the counts behind the rows differ by an order of magnitude between the early residual sweeps and the ported operators. The recommended placement reaches \SwinRecommendedAurocAdaptive{} at the adaptive rule on \SwinRecommendedN{} cells. \Cref{tab:swin-gains} pairs it within cell. Against the published placement the gain is \SwinGainRecommendedMinusPublished{} with interval [\SwinGainRecommendedMinusPublishedLow{}, \SwinGainRecommendedMinusPublishedHigh{}] on \SwinGainRecommendedMinusPublishedN{} cells, and against the founding pre-residual placement \SwinGainRecommendedMinusPreResidual{} with interval [\SwinGainRecommendedMinusPreResidualLow{}, \SwinGainRecommendedMinusPreResidualHigh{}]. Dropout at the same attention input, which is the position without the operator, reads \SwinGainDropoutInputMinusPublished{} against the published placement with an interval that includes $0$. On Swin the gain arrives with the token mask at the attention input and not with the position alone, which is the same lesson as \cref{sec:placement} read from a second architecture, that the specific placement carries the effect and neither axis does by itself.
